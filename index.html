1. How a website works

Key points

  • A website is a folder of files stored on a server.
  • A browser (Chrome, Safari, Firefox) requests the files and displays them.
  • HTML = structure, CSS = style, JavaScript = behavior.
The three languages of the web
LanguageJobAnalogy
HTMLDefines the content and structureWalls and rooms
CSSControls colors, fonts, layoutPaint and furniture
JavaScriptMakes the page interactiveElectricity

2. Page structure

Every HTML page has the same skeleton.

<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Tab title</title>
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    ...everything visitors see...
  </body>
</html>
  • <head> holds information about the page (title, CSS link).
  • <body> holds the visible content.
  • Most tags come in pairs: an opening <p> and a closing </p>.

Remember: name your home page index.html. Servers look for that name first.

3. Headings

HTML has six heading levels. <h1> is the most important, <h6> the least.

<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>

  • Use one <h1> per page, as the main title.
  • Don't skip levels (for example, h2 straight to h4).
  • Pick headings for meaning, not for size. Use CSS to change size.

6. Tables

Tables show data in rows and columns. Don't use them for page layout.

<table>
  <thead>
    <tr><th>Subject</th><th>Marks</th></tr>
  </thead>
  <tbody>
    <tr><td>Maths</td><td>90</td></tr>
    <tr><td>Science</td><td>85</td></tr>
  </tbody>
</table>

Maths90
Science85

7. Links & images

<a href="https://github.com">Go to GitHub</a>
<img src="photo.jpg" alt="A student reading a book">
  • href is the destination of a link.
  • src is the image file to show.
  • alt describes the image for screen readers and when the image fails to load.
  • A link to another page in your folder is written <a href="about.html">.

Remember: href, src and alt are attributes. They add extra information inside the opening tag.

8. Forms

<form>
  <label for="n">Name</label>
  <input id="n" type="text">
  <label><input type="checkbox"> I agree</label>
  <select>
    <option>Grade 9</option>
    <option>Grade 10</option>
  </select>
  <button>Send</button>
</form>



  • <input type="..."> can be text, email, password, checkbox, radio, number and more.
  • Always connect a <label> to its input with matching for and id.

9. CSS basics

A CSS rule has a selector and declarations.

h1 {
  color: navy;        /* property: value; */
  font-size: 32px;
}

11. Practice

Check your understanding

Click a question to reveal the answer.

Which language controls the colors of a page?

CSS.

What is the difference between ul and ol?

ul makes bullets (order doesn't matter). ol makes numbers (order matters).

Which tag makes a table header cell?

<th>.

Why should every image have an alt attribute?

It describes the image for people using screen readers and shows if the image can't load.

What is the difference between margin and padding?

Padding is space inside the border. Margin is space outside it.

Mini exercises

  1. Create a page called about-me.html with one h1 and two paragraphs.
  2. Add a bullet list of your three favorite subjects.
  3. Add a table of your weekly timetable (at least 3 rows).
  4. Link index.html to about-me.html.
  5. Create style.css and change the background color and font.

12. Publish on GitHub Pages

  1. Create a free account at github.com.
  2. Click New repository, name it, and keep it Public.
  3. Click Add file, then Upload files, add index.html and style.css, then Commit changes.
  4. Go to Settings, then Pages. Choose the main branch and click Save.
  5. After a minute, visit https://your-username.github.io/your-repo-name/.
